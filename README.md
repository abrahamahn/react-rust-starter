# React Rust Starter

Standalone React + TypeScript frontend and Rust + PostgreSQL backend, extracted
from selected BSLT logic. Development happens on `main`.

**Bootstrap in progress. Not a completed starter or production release yet.**
The initial backend includes selected authentication/session behavior, email
verification/recovery and an owner-scoped notes example. UI integration, generated
lockfiles, end-to-end verification and adoption instructions are being completed.
No existing BSLT runtime, private history, environment file or customer database
is part of this repository. No public deployment is configured.
